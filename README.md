# Şarj Kablosu Düğüm Laboratuvarı

Bu depo bir şaka değildir. Bu depo, şakanın üstüne damga basılmış hâlidir.

Çantaya düz, uysal ve neredeyse medeni bir şarj kablosu koyarsınız. Çantayı açtığınızda kablo artık bir düğümdür. Düğüm özür dilemez. Düğüm tutanak tutar. Bu laboratuvar, o tutanağı milisaniye ciddiyetinde hesaplar.

Patates yoktur. Dolmuş yoktur. Asansör suskunluğu başka dairenin işidir. Burada sadece kablo, cep ve kader vardır.

## Ne işe yarar

Gerçekten çalışır. Girdi alır, düğüm katsayısı üretir, kaç saniye küfüreceğinizi söyler, USB ucunun hangi yönde yalan söyleyeceğini raporlar.

## Kurulum

```bash
python3 dugum.py
python3 dugum.py --dakika 14 --cep dar --acele var
python3 dugum.py --demo
```

Bağımlılık yoktur. Kablo zaten bağımlılıktır.

## Bilimsel yöntem

1. Kablo çantaya girer.
2. Çanta kapanır.
3. Fizik kanunları izin ister.
4. İzin reddedilir.
5. Düğüm doğar.

Laboratuvar bu beş adımı deney sayar. Deney her seferinde aynı sonucu verir. Bu, bilimin zaferidir.

## Katkı

Kabloyu düz gönderen pull request kabul edilmez. Düğümü artıran pull request ciddiyetle incelenir, sonra yine düğüm olur.
